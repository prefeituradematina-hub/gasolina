🔐 Migração de Usuários para o Firebase Authentication

Etapa C1 — cria uma conta de autenticação para cada usuário já existente no sistema.

⚠️ O que esta ferramenta FAZ:
• Lê os usuários do nó usuarios
• Cria uma conta correspondente no Firebase Authentication (e-mail interno + a senha atual)
• Grava o uid gerado de volta no registro do usuário

O que ela NÃO faz:
• Não apaga nem altera nenhum outro campo do usuário
• Não altera senhas
• Não mexe no login do sistema (ninguém é afetado ainda)
• Não toca em abastecimentos, veículos ou qualquer outro dado
🚨 ANTES DE RODAR:
1. Ative E-mail/senha em Firebase Console → Authentication → Sign-in method
2. Faça um backup do nó usuarios (Realtime Database → Dados → menu ⋮ → Exportar JSON)
3. Rode primeiro em modo simulação para ver o que aconteceria, sem gravar nada
